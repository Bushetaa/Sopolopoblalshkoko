# Implementation Plan: Analytics Engine

**Branch**: `002-analytics` | **Date**: 2026-04-19 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `specs/002-analytics/spec.md`

## Summary

Implement the Analytics Engine page for the Sopo Platform — a data-dense dashboard section displaying real-time API health via KPI metric cards, interactive multi-series charts (traffic area, donut distribution, response-time histogram, status-code stacked bar), SLA KPI tracking with health status, and a live log feed with pause/resume and filtering. All data is mock-generated client-side (no backend required for v1). The page lives at `app/(dashboard)/analytics/` within the Next.js App Router route group established by Spec 001.

## Technical Context

**Language/Version**: React 19, Next.js 16, TypeScript  
**Primary Dependencies**: Recharts 2.x (already installed), Lucide React, Tailwind CSS v4, date-fns  
**Storage**: N/A — all data is mock-generated client-side via custom hooks  
**Testing**: Jest, React Testing Library  
**Target Platform**: Web browsers (Chrome, Firefox, Safari); responsive to 768px+ (tablet) and 1440px (desktop)  
**Project Type**: Next.js App Router — `app/(dashboard)/analytics/page.tsx` and sub-routes  
**Performance Goals**: Chart renders < 100ms on filter change; KPI refresh < 30ms; live feed entry < 50ms  
**Constraints**: Dark mode only (`bg-gray-950`/`bg-gray-900`); no horizontal scroll at any breakpoint; zero React console warnings  
**Scale/Scope**: Single-page analytics module; self-contained within `app/(dashboard)/analytics/`

## Complexity Tracking

| Violation | Why Needed | Simpler Alternative Rejected Because |
|-----------|------------|--------------------------------------|
| Dual Y-axis `TrafficChart` | Requests + p95 latency live on completely different scales (0–100k vs. 0–500ms) — sharing one axis makes both unreadable | Single Y-axis makes either requests or latency completely unreadable |
| `setInterval` in `useLiveLogs` | Required to simulate real-time event streaming behavior specified in acceptance criteria | Static data cannot fulfill "new entries appear every 1–2 seconds" requirement |
